The first build was a simple python appointment booking system for SmartCare. First created basic input and output statements with two example appointments. Then improved the program by using a list, dictionaries, and functions to make the code more organized and reusable. Basic validation was added to prevent an appointment from being created without a patient name.
AI helped me understand how the system could be improved by identifying a potential duplicate-booking problem. It showed me how a booking system should check whether a practitioner is already booked at the same time. This helped me understand the importance of validation and considering real-world requirements when designing software.
However, AI made assumptions about my existing code and data structure. For example, its suggested code changed the appointments structure from a list to a dictionary but still used methods such as append(), which would not work with a dictionary. It also used different dictionary key names from my original program.
I verified the AI output by reading the code carefully and checking whether the data structures, variable names, and functions were consistent. I also considered whether the proposed changes actually solved the booking problem.
The engineering work that remained for me was correcting the AI-generated code, testing it, identifying errors, and deciding which suggestions were appropriate for my system.
